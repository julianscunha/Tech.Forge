# Changelog

Todas as mudanças relevantes da plataforma Core do TechForge são documentadas
aqui. Formato baseado em [Keep a Changelog](https://keepachangelog.com/) —
seções permitidas por versão: `Added`, `Changed`, `Fixed`, `Deprecated`,
`Removed`, `Known Issues` (spec Fase 15 §26).

Este changelog cobre o **Core** apenas. Cada módulo mantém seu próprio
`CHANGELOG.md` na raiz do módulo — não misturar releases de módulo com
releases do Core (spec §27).

Para o histórico detalhado por fase, ver `tasks/phase-*-report.md`.
